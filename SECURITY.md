# Security policy

fm renders untrusted Mermaid labels into SVG that may be shown in a browser,
so sanitisation bugs count as security issues.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's
"Report a vulnerability" button on the repository's Security tab.

Include the fm version, the flowchart and state that trigger the problem, and
what you expected. You should get a reply within a week.

## Supported versions

Only the latest release receives fixes.
